# GLOSSARY — 文旅短视频提示词术语表

> 收词原则：只收"动手时会遇到、不懂就会做错"的词；每条给**在这套素材里的特定用法**，不是字典释义。
> 共 39 条，分五组。`必写` = 写提示词时必须出现的字段；`条件写` = 视题材追加；`不进提示词` = 只用于拆解/评估。

## A. 拆解与测量（13 条）

| 术语 | 素材中的用法 | 易混淆 / 备注 | 提示词 |
|---|---|---|---|
| 拆解报告 | 对成片的结构化客观记录，十段：结论/角色场景/叙事结构/分镜表/剪辑包装/声音/画面测量/复刻要点/不确定点/产物索引 | 不是影评，不含好坏评价 | 不进提示词 |
| 分镜表 | 逐镜记录 #/时间/时长/景别/机位/运镜/制作方式/置信度/叠加层/转场 | 不是分镜脚本（没有画面描述） | 不进提示词 |
| 制作方式（判定） | AI 生成 / 实拍 / 代码模板渲染，可混合；附置信度 | 不是二选一标签，允许"证据不足" | 不进提示词 |
| 置信度（⚠ 待复核） | 工具对判断的把握程度；<0.6 标 ⚠ 转人工看图 | 置信度低 ≠ 结论错，但不可当事实 | 不进提示词 |
| 「看得见的」与「推断」 | 画面可直接观察到的（颜色/动作）vs 由线索推出的（拍摄意图） | 推断不能写成原片事实 | 不进提示词 |
| 工具原始结论 / 我的判读 | 工具输出的原始判断 vs 人工修正后的判读，两者都要留 | 修正要留痕，不能抹掉 | 不进提示词 |
| 画面基准 | 景别配比/机位比例/运镜/主光/光比/色温/调色/刀数，用于写提示词 | 不是拍摄方案；AI 片是"画面里的光影" | 必写 |
| 光比 | 主体亮部与暗部的亮度差，写成"约 1.3:1（相差 0.4 档）" | 素材中 0.4/0.3 档两种记法并存 | 条件写 |
| 刀 / 分钟（平均镜头时长） | 每分钟切镜次数与平均镜头长度，是分段与单元切分依据 | 刀数高 ≠ 好看，只是节奏口径 | 条件写 |
| 同机位跳切 / 推近切 | 同机位直接跳接 / 机位不动只推近的切法 | 用于快剪段落制造"轰炸感" | 不进提示词 |
| 插入画面（占比） | 与主线无关的短插入镜（如节日大字、足球段） | 常被误当主线，拆解时要单列 | 不进提示词 |
| 生成单元 G / 拍摄场次 S | G = 一次生成任务的镜头打包（≤15s）；S = 一次实拍场次 | AI 片用 G，实拍用 S，不可混用 | 必写（G） |
| 视觉母题 | 贯穿全片的重复意象（玻璃球、银杏、银冠），通常回环三次 | 母题是结构件，不是装饰 | 必写 |

## B. 提示词结构（6 条）

| 术语 | 素材中的用法 | 易混淆 / 备注 | 提示词 |
|---|---|---|---|
| 全局提示词 / 通用风格前缀 | 画幅+帧率+风格+色调+景深+主角+场景质感，每段重复带 | 不是只写一次的开头 | 必写 |
| 使用参考视频（锁定指令） | "照它的分镜数、时长、景别、机位和剪辑节奏生成" | 用于图生视频/参考生成 | 条件写 |
| 负向约束 | 四段式：合规句 / 画面污染 / 主体失真 / 题材专属 | 不是一句"不要崩"就够 | 必写 |
| 客观化改写（三步） | 主观→事实；程度→画面元素；排名/承诺→删除或中性 | 不是润色，是可判定替换 | 必写（合规句） |
| @图片N（先定义主体） | 用参考图时先写"将@图片1 中的人物定义为主角，保持外貌与服饰一致"，再写动作 | 不先定义主体，模型会换脸 | 条件写 |
| 跨镜头同一张脸（人物设定段） | 跨单元复用同一段主体描述（脸/发型/妆/服装套数） | 不是每镜重写一遍 | 必写（有人物时） |

## C. 槽位与替换（5 条）

| 术语 | 素材中的用法 | 易混淆 / 备注 | 提示词 |
|---|---|---|---|
| 变量槽位 / {{占位符}} | 提示词里可替换的变量，配"默认值/角色/可替换为"三列 | 不是程序变量，是替换清单 | 必写 |
| 五连槽 | 赛事/活力—生态/标志物—历史/古道—文博/科技—美食/烟火 | 只适用于"一城物产清单"结构 | 条件写 |
| 模板版 / 示例版（双版本） | 模板版带占位符用于定制；示例版填原值用于复刻原片 | 两版必须可 diff，差异只在槽位 | 必写 |
| 三个自定义入口 | 给文字 / 给图 / 用推荐模板（三级降级） | 降级顺序固定，禁止反问空白问题 | 不进提示词 |
| 换城 | 只改变量不动结构：换 city、地标、人物、元素、美食 | 不是全局替换城市名 | 不进提示词 |

## D. 包装与声音（10 条）

| 术语 | 素材中的用法 | 易混淆 / 备注 | 提示词 |
|---|---|---|---|
| 包装层 | 字幕/花字/文字标注/贴纸/标题/常驻图层/片尾卡的总称 | 与画面同级，不是"随便加的后期" | 不进提示词（后期叠） |
| 字幕 | 台词文字，白字描边，字高约占画面高 3–6% | 不同于花字：字幕是信息，花字是强调 | 不进提示词 |
| 花字 | 字号大、多色/渐变、倾斜的强调字（"真""看"） | 全片通常只有 0–7 处 | 不进提示词 |
| 文字标注 | 地名/账号/技术名词等说明文字，可跟随物体移动 | 常被误当字幕，拆解要单列计数 | 不进提示词 |
| 常驻图层 | 跨切镜不变的贴纸/标识，整段叠一次 | 逐镜生成会闪烁 | 不进提示词 |
| 按台词定位 | 卡点写成"某句说完后 0.2s"，不写绝对秒数 | 换文案后自动跟着走 | 不进提示词 |
| 音效卡点 | 音效对齐文字/贴纸出现或切镜的位置 | 不是"随便加个音效" | 不进提示词 |
| 卡点剪辑 | 是否按音乐节拍切镜（布尔值） | 多数样片为 False，不要默认开 | 不进提示词 |
| BPM·段落变化 | 配乐速度与段落起伏次数（85–167，中位约 126） | 素材多标"待确认"，只给区间 | 不进提示词 |
| 声音来源 | 人声 TTS / 现成曲库 / 音效库 / 后期添加，四选一 | 纯 BGM 必须显式写"不要人声" | 条件写 |

## E. 制作与合规（5 条）

| 术语 | 素材中的用法 | 易混淆 / 备注 | 提示词 |
|---|---|---|---|
| 复刻路线 | 实拍为主 / AI 为主 / 混合（AI 只做转场包装） | 由制作方式判定 + 地标真实性决定 | 不进提示词 |
| 合规红线·禁用词 | 极值排名 / 绝对化 / 主观夸大 / 功效承诺 四类 | 作用域只限自撰文案，原片台词不改 | 必写（合规句） |
| AIGC 标识 | 平台要求的 AI 生成内容标识 | 素材只提及，未给法规细则 | 不进提示词 |
| 复刻准备清单 | 演员/道具/地标/参考图/素材的清单 | 随片变化，是模板不是固定项 | 不进提示词 |
| 待确认 | 影响复刻路线的不确定项（制作方式/台词/BPM/来源/技术名词） | 不能藏进正文，必须单列 | 不进提示词 |

## 三组最易混（速查）

| 容易混 | 区别一句话 |
|---|---|
| 字幕 vs 花字 vs 文字标注 | 字幕=台词；花字=情绪强调；标注=地名/账号/名词。三者计数与位置都不同。 |
| 模板版 vs 示例版 | 模板版给人改（带 `{{}}`）；示例版给人抄（原值）。两版可 diff 还原。 |
| 制作方式 vs 画面基准 | 制作方式回答"这是怎么做的"（AI/实拍/模板）；画面基准回答"画面长什么样"（景别/光比/色温），用于写提示词。顺序：先定制作方式，再决定基准怎么读。 |
