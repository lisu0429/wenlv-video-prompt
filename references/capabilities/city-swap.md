# 换城 / 换人 / 换场景

## R — 原文

> "第 3 步 · 不提供就推荐模板：用户不给、或说「你推荐 / 随便 / 不知道」→ 直接给出 0.4 节推荐模板库中对应类别的 3 个候选（明确列出来让用户选），**不要反问空白问题**；用户选定后填入。"

>
> —— `01_四川/拆解视频的提示词.md` §0.4 城市模板（五连槽）

## I — 自述

换城不是"全局替换城市名"，而是**只改变量、不动结构**。要改对，靠三样东西：

1. **三个入口**：用户给文字（人物/城市/场景描述）→ 填槽位；用户给图（1–2 张：近景 + 全身）→ 用 `@图片N` 引用并先定义主体（"将@图片1中的人物定义为主角，保持外貌与服饰一致"），再写动作；用户不给 → 给推荐模板的 3 个候选让他选。
2. **四步降级协议**：索要素材 → 按给的内容处理 → 不给就给 3 个候选（**禁止反问空白问题**）→ 合规校验后交付，并列一行"本次改了哪些槽位"。
3. **槽位表（四列）**：占位符 / 本片默认值 / 槽位角色 / 用户可替换为。命名按族：`{{city}}`、`{{character}}`、`{{character_style}}`、`{{scene_main}}`、`{{scene_1..n}}`、`{{landmark}}`、`{{element_1..n}}`、`{{food_1..n}}`。**人物与服饰必须拆成两个槽**（换人不等于换衣服）。

城市级替换用**五连槽**：赛事/活力 → 生态/标志物 → 历史/古道 → 文博/科技 → 美食/烟火，顺序不调换。每个槽必须给出一个"具体画面证据"（火炬、熊猫、青铜器、火锅级别）；给不出就换槽内容，**不许留空，也不许硬凑**。

**动作也要换载体**（ce21）：模板里被冻结的不只是名词，还有动词短语——"骑马穿巷""与动物合影""手持火炬行走"。这些动作绑定原地的地形、设施与许可，换城时要逐镜问一次"这个动作需要什么条件"，分成三类：可照搬（走动/观看/进食）、需换载体（骑马→步行、火炬→手持无人机）、需删除（只有原地成立）。换载体时保留**功能位**而不是删掉——"远处雪山泛亮"可换成"巷尾海面泛亮"。

**载体要有"识别度"，不是有个名字就行**（ce36，field-observed 2026-11-25，用户原话"在你发的视频没看到云南的特色"）：换城时按"填槽表"逐项替换了名称（壮族→白族、桂林→苍山、鸬鹚→白鹭），成片却像通用山水——因为换上的全是**弱识别载体**：头帕一闪而过、扎染缩成山上的圆点纹、山画成通用青绿、船是通用木船。判断标准不是"槽位换没换"，是"**观众盲测能不能认出这是哪**"。规避＝每个目标城市先列 3–5 个**强识别载体**（轮廓独一无二的地标如苍山雪顶/洱海月/崇圣寺三塔，或独占文化符号如扎染的实际纹样而非泛化圆点、孔雀/大象），并要求在画面里**占够面积或时长**（不是一闪而过）；交付前做盲测——把片子给人看问"这是哪儿"，答不出＝载体没落地，不算完成。写进提示词时要给具体形状描述（"三塔的塔身轮廓""扎染的螺旋与冰裂纹"），不要只写"云南特色"四个字。

校验法：提示词里出现的每个专有名词，都要能在槽位表里找到归属；表里的每个槽，都要在提示词里被用到。

## A1 — 应用示例

**原片案例（01_四川 五连槽）**：赛事/活力＝城市足球赛与火炬传递；生态/标志物＝大熊猫基地；历史/古道＝茶马古道雪山古城；文博/科技＝三星堆青铜器；美食/烟火＝川式火锅。五槽各对应一条 `{{scene_*}}` 占位符，换城时逐槽替换。

**原片案例（22_山西 槽位命名族）**：用 `{{landmark_1..6}}` 承载晋祠、平遥、乔家大院等地标，证明"多场景"不必每个都起语义名，按出现顺序编号即可。

**合成演练（非原片事实）**：把四川模板换成绍兴，可用资源＝黄酒、兰亭、乌篷船、古纤道，**没有大型赛事**。按本卡：`{{city}}`=绍兴；四个槽可填（黄酒封坛＝美食/烟火、兰亭＝文博、古纤道＝历史、乌篷船＝生态）；"赛事/活力"槽缺口 → 触发不适用分支，给两条出路：① 换成"黄酒开坛仪式/龙舟"作为活力证据；② 降级为单线叙事（走 `story-structure`），不硬塞五段。预期输出：5 行替换表 + 一句缺口说明 + 替换后的完整提示词。

**实战案例（2026-11-23 · 01_四川 → 深圳，实际执行记录，非素材）**：

- 五连槽：马拉松（深南大道）/ 深圳湾红树林越冬候鸟 / 大鹏所城 / 深圳科学技术馆（光明）/ 沙井炭烤生蚝
- 人物两槽：`{{character}}`=1983 年来深的建设者（虚构，可换真人）、`{{character_style}}`=劳动布工装 + 军绿帆布挎包 + 白回力鞋
- 三处**动作换载体**：骑马穿巷→步行穿巷；与熊猫合影摆拍→栈道上举望远镜观鸟；手持火炬行走→手持折叠无人机 + 编队升空
- **保留功能位**：原片"远处雪山在阳光下泛亮"→"巷尾露出的海面在阳光下泛亮"（都是背景自然景观发亮，构图与节奏不变）
- 新增负向约束：`不要出现马匹、雪山、熊猫、火锅`——不写死，模型会按原片惯性补回
- 交付形态：五连槽表 + 6 段全填好的提示词 + 三处降级说明 + 合规自检（禁用词 0 命中）
- **教训**：换城真正难的不是填槽，是判断"哪些动作是原片地形专属"。填槽半小时，判断动作载体才是关键（沉淀为 ce21）

> 这是本卡第一个跑完全流程的真实案例。它证明规则可执行，但**不代表效果已验证**：降级后的画面没有做生成验证，样本仅 1 个城市。

## A2 — 触发情境

**用户会在这些时候需要它**：
1. 手里有一份别处的提示词模板，想换成自己城市/自己人物。
2. 做系列内容：同一结构要套到多个城市（省内地市巡礼）。
3. 客户临时改主角（"把杜甫换成汉服姑娘""换成我们局长"）。
4. 只想改局部（"夜景改白天""去掉火锅那段"），不想重写全文。

**语言信号**：`换成我们城市`、`换个人物`、`换成 XX`、`套到我们这儿`、`改成白天/改成夜景`、`去掉这段`、`swap the city`、`replace the character`、`adapt this template to`。

**与相邻能力的区分**：本卡只改变量（人物/城市/场景/元素），不改结构与节奏；若要改结构 → `story-structure`；若要重写镜头提示词 → `prompt-pack`；若新文案含夸大词 → `compliance-rewrite`（本卡最后一步内置调用）。

## E — 执行

**输入契约（必需）**
- 一份现有提示词模板或槽位表（无则先用 `prompt-pack` 生成）。
- 变更意图：换什么（城/人/场景/元素/时间/风格）。

**缺失处理**：用户只说"换一下"而无具体对象 → 按四步协议第 1 步索要（图片或文字）；仍不给 → 给 3 个候选，禁止空转追问。

**步骤**
1. 解析意图，归入六类：换人物 / 换场景 / 换城市 / 改风格 / 改镜头 / 改文案语气 / 去元素。
2. 映射到槽位（"杜甫换汉服姑娘"→ `{{character}}` + `{{character_style}}`；"夜景改白天"→ `{{scene_street}}` 的时间描述）。
3. 素材三级降级：图片（`@图片1` 先定义主体）→ 文字描述 → 3 个候选模板。
4. 换城时走五连槽：逐槽填 + 每槽一个画面证据；缺槽 → 换内容或降级结构，写进交付说明。
5. 动作载体检查（逐镜）：该动作需要什么地形 / 设施 / 许可？分三类处理——照搬 / 换载体 / 删除；换载体时保留功能位，并在负向约束补一条"原片专属元素"。
6. 人物一致性：跨单元复用同一段主体定义（脸/发型/妆/服装套数/参考图），不每镜重写。
7. 合规校验：对新填入文案执行禁用词检查，命中即改写。
8. 交付：完整提示词 + 一行"本次改动槽位清单"。

**输出契约**
- 替换表：槽位 / 原值 / 新值 / 依据（用户提供 or 推荐模板）。
- 替换后的完整提示词（占位符全部填好，可直接复制）。
- 缺口说明（哪些槽没填、为什么、走了哪条分支）。
- 改动清单（一行）。

## B — 边界

- **不要用**：要 1:1 复刻原片（此时不该换主体）；结构本身不适用新城市且无法降级时（应先回 `story-structure`）。
- **作者警告的失败模式**：只换 `{{city}}` 不换地标名（ce06）；换城硬凑五连槽（ce05）；示例版残留占位符（ce07）；换人物只换衣服不换脸（ce20）；跨镜人脸不一致（ce08）；把原片动作整体搬走、动作与地形不匹配（ce21）。
- **反例速查**：本卡引用的 `ce` 编号见能力包根目录的 `resources/case-index.md` 末节「反例索引（36 条）」，一句话教训 + 证据等级；16 条是实测（`field-tested`，含 ce26–ce36 用户付费生成实测与成片/转场/原片复盘反馈），其余为文档明示或推断。
- **作者盲点**：五连槽假设"每个城市都有五类资源"，现实中大量城市没有赛事级 IP。**已用深圳实战检验过一次**（2026-11-23）：规则可执行，但降级后的画面效果未做生成验证，且只有 1 个城市样本，跨城稳定性仍未验证。
- **与视频参考互斥（实测）**：换城不能用 B 路（给参考视频）。参考视频会把**参考片的场景**一起带过来，优先级高于文字——实测同一句提示词写「青城山雾气与竹林」，无参考视频生成竹林，加了山脊参考片就生成山脊。也就是说，拿原片当参考视频去生成目标城市的画面，出来还是原片那个城市，换城白做。要换城，只能用 A 路（按单元切短 + 文字描述），或者换一条目标城市拍的参考片。
- **易混淆**：`prompt-pack`（从零装配提示词）；`compliance-rewrite`（只做文案合规，不动槽位）。
- **共同纪律**：七卡共用一套判定纪律（先测量后动笔 / 结构先定 / 分层不混 / 结果可复核 / 缺料走降级 / 证据分级 / 出彩可指认），全文见 SKILL.md「核心原则」；本卡只展开本域，跨域冲突以那 7 条为准。
