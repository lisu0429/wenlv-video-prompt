## I — 自述

包装与声音是"完成度"的来源，也是最容易被漏掉的一层。它们不进生成提示词（不让模型画字），而是**后期叠加**，所以要单独出一份规格表。

**包装层八类**：字幕（句数/字高占比/位置/描边/高亮规则/入场方式）、花字（强调字，字号大、多色、倾斜）、文字标注（地名/账号/技术名词，注明几处跟随物体移动）、贴纸/动图、标题、**转场**、常驻图层、片尾转化位。

四条硬经验：
1. **常驻图层跨切镜不变**，整段叠一次即可，不要逐镜生成——否则每镜重复会闪烁。
2. **按台词锚点定位**，不按绝对秒数（"某句说完后 0.2 秒"）——换文案后卡点自动跟着走。
3. **转场单列一层**（field-observed，2026-11-24）：转场不能只写在生成镜头句末尾，必须在包装规格表里单列一行，写清内容/位置/样式/入场/锚点——否则生成端权重过低，实测做不出来。转场形态按 `prompt-pack` 的纪律逐帧实测后拆成可数步骤，核对原片有无黑场（`blackdetect`），有就写时长与位置、没有就明写「不做全黑场」。转场音效（whoosh/riser）卡点要对齐色块切入帧，不要挂在黑场里——原片无黑场时音效落点在几何色块切换处。**⚠ 手法优先级见 `prompt-pack` 纪律第 5 条（ce33）：形变衔接 > 主体运动带出 > 首尾帧续写 > 墨晕遮罩兜底；先逐帧拆原片用什么手法，别默认套遮罩。**
4. **"移交后期"不是交付，先确认用户有没有后期环节**（ce31，field-observed 2026-11-25）：默认用户拿到生成片直接发布，不会自己叠遮罩。交付前必须问清"你有没有后期剪辑环节"：①**没有** → 把转场做成**交付物本身**——直接合成一条带遮罩的成品 MP4 交付（不只是规格表），或者改用支持首尾帧续写的工具在生成端衔接；②**有** → 才交规格表 + 明确写"这一步需要你手动叠"。把遮罩只写进 packaging 表、默认用户自己会做，等于没设计——用户看到的就是全片硬切。

**转场落地的两条路（按用户工具能力选，交付前必问）**：
- **生成端首尾帧续写**（用户工具支持时优先）：上一段末帧作下一段首帧参考图，切点天然衔接。边界：首尾帧只保"画面衔接"，**不保主角一致性**——同一主角仍须给同一张设定图作参考（见 `prompt-pack` ce 跨段一致性条）。
- **后期墨色遮罩合成（兜底遮丑，非正解，ce33）**：原片没有这种转场，仅用于"已生成片返工 + 用户无后期"时减轻硬切感，做不出原片的形变丝滑。**切点必须按实测、不按设计**（ce32）——设计 2.9/6.6/14.7s，实测 4.0/5.75/14.5s 全错位（生成端重排了单元时长）。定位法：`fps=4` 抽帧拼图肉眼找"旧画面最后一帧 / 新画面第一帧"，scene 检测只作参考。合成法（本机实测可用）：numpy 生成灰度遮罩 raw（切点 ±0.22–0.30s、满墨平台 0.04–0.06s、墨色从边缘洇入盖满再退去，峰值帧整幅=255 不留中心洞），`ffmpeg -f rawvideo -pix_fmt gray -s 320x180 -r 30 -i mask.raw` 读遮罩 → `scale=1280:720:flags=gauss` → `[原片][纯色墨底][遮罩]maskedmerge` 合成 → 音频 `-c:a copy` 保留。**验收必查**：`blackdetect` 无全黑场、峰值帧中心与四角都盖住、洇入窗口别太长（>0.4s 画面会发闷）、噪声项别用高频随机（会出现白亮斑）、退去后无残影。遮罩色取青墨 `0x3a5a52` 等非纯黑，避免误触黑场检测。

**落款固定值**（user-specified，2026-11-24）：常驻图层与片尾署名一律「环球数字文旅」，不用城市文旅占位、不带抖音号；若片尾转化位被删除，须在落版欢迎语下方补一行片尾落款，避免成片无署名。

**声音层**：先判"有人声/纯 BGM"，再定 BPM 与段落起伏，最后排音效卡点。纯 BGM 必须**显式写"不要人声、不要歌词"**，否则模型容易加旁白。BPM 只给区间与风格（素材中 85–167，中位约 126），不冒充精确曲目。

**音轨能量纪律（ce34，field-tested 2026-11-25 完整原片逐轨复盘）**："有没有声音"不够，要看**能量曲线**。原片 20 秒全程 0 静音、均值 -12.8dB，峰值精确压在视觉奇观上（15.0s 炸墨 -10.0dB），铺垫段也有 -17dB 底、结尾淡出收束。生成片 16.4% 帧静音、9–13.5s 掉到 -37~-49dB，画面在该高潮的地方没声音托着——这是用户觉得"平"的另一半根因。**交付/验收必查三件事**：① `silencedetect=noise=-40dB:d=0.3` 全程**零静音段**（任何 0.5s 窗口不低于 -30dB）；② 用 PCM 50ms 窗算 RMS 曲线，**音量峰值对齐视觉奇观**（不是随便起伏）；③ 有完整收束（结尾淡出），不戛然而止。检查命令：`ffmpeg -i V -vn -ac 1 -ar 8000 -f s16le audio.pcm` 后 numpy 分窗。纯 BGM 也要写清"全程不断、峰值卡在 XX 秒的奇观上"。

**音频分析的可靠度边界（借鉴 rea-video audio 卡实测，2026-11-25）**：分清哪些能当证据、哪些只能当线索——
- **可信**：有无人声、有无 BGM、BPM（打击成分自相关）、音量能量曲线、静音段。这些用于验收。
- **不可信，必须标"待人工确认"**：**音效卡点**（信号层在人声+BGM 混音里精度仅约 0.2，轻音效基本测不出）、TTS vs 真人、配乐具体来源。写报告时音效写"约 X 秒，待人工听确认"，不要写成确定值。
- **配乐来源**：AI 工作流也常用 Suno 配乐，"普通配乐＝现成曲库"的先验会错。写方案时标"倾向曲库/AI 生成，待确认"，给确认方法：①平台原页面的音乐标签 ②听歌识曲（识别得到=现成曲；识别不到≠AI）③听感（AI 歌咬字含糊、器乐结构一成不变、结尾突然收住）。我们交付的是提示词包，用户自己生成，来源判断的责任边界要写清。

**人声与画面嘴型是两层，别混**：本卡只管"声音放什么"，不管"画面上人物是否在开口"。实测（ce25）证明，图生视频里写"对镜头说话"不会让嘴唇开合——口型归音轨，没有音频输入就不生成。所以排人声前先确认画面来源：真人实拍口播可原样配音；AI 生成的人物若需开口，须走数字人 / lip-sync 单独成片，不能靠提示词，也不能靠后期把嘴"贴"上去。**画面上不开口的方案（旁白 + 人物在场景里的动作镜头）是成本最低、最稳的一条**，27 篇原片里有相当一部分就是这个结构。

## A1 — 应用示例

**原片案例（01_四川）**：字幕 46 句（白字白描边、字高 3.6%、说到关键词变色）、花字 3 处（"唐代现实主义诗人""真""看"）、文字标注 60 处（其中 9 个跟随物体移动）、贴纸 1 处、常驻图层 2 个；声音为旁白 + 139.7BPM 配乐 + 10 处音效（ding×7、whoosh×2、pop×1）；并给出 3 处按台词定位的卡点。

**原片案例（12_广西）**：包装以表格交付（城市标签左下角白字细描边、AI 标识右上、机构标识右下常驻、片尾 3 秒搜索卡）；声音为纯 BGM（电子国风 + 史诗鼓点），前 8 秒空灵、28 秒车行段降下来、63 秒快剪段拉满、结尾 8 秒收干净，转场用 whoosh 与低频 riser。

**合成演练（非原片事实）**：40 秒无人物风景片，交后期。按本卡产出：字幕 12 句（底部、白字黑描边、字高 4%）、地名标签 5 处（左下角，随段落切换）、片尾 3 秒搜索卡；声音为纯 BGM（国风弦乐，90–110BPM，前 4 秒留白、25 秒起加鼓、结尾 3 秒收干），音效 3 处（转场 whoosh ×2、片尾 ding ×1），并注明"不要人声"。

## A2 — 触发情境

**用户会在这些时候需要它**：
1. 片子剪完了，要定字幕样式、花字位置、片尾引导。
2. 要交付后期，需要一份能照着做的包装规格表。
3. 换文案后卡点全乱了，想知道怎么让卡点跟着台词走。
4. 配乐选不准，需要 BPM 区间与段落起伏建议。

**语言信号**：`字幕怎么排`、`花字`、`文字标注`、`包装层`、`配乐节奏`、`卡点`、`片尾引导`、`subtitle style`、`on-screen text`、`music cue`、`BGM tempo`。

**与相邻能力的区分**：本卡只管后期叠加层与声音，不写生成提示词（→ `prompt-pack`）；不测原片包装数据（→ `deconstruct`）。若用户要的是"让 AI 在画面里生成文字"，应先纠正：文字一律后期叠，不用模型画。

## E — 执行

**输入契约（必需）**
- 成片或分镜/脚本 + 总时长。
- 台词表（有人声时）或"无台词"声明。
- 交付对象（自剪/外部后期）。

**缺失处理**：无台词表 → 按分镜段落给"段落地名标签"作为替代锚点。

**步骤**
1. 判包装强度：官方号/信息型 → 字幕 + 地名标签 + 片尾卡；纯视觉片 → 仅片尾标识。
2. 出包装规格表：类型 / 内容 / 位置 / 样式（字号占比、颜色、描边）/ 入场 / 节奏——**八类逐项过，转场单列一行**，写清形态步骤与末帧分割。
3. 标常驻图层：哪些跨切镜不变，整段只叠一次；**署名填固定值「环球数字文旅」**。
4. 写按台词锚点：每处写成"某句开始/结束后 X 秒"；无台词的地标/转场用画面锚点（"某地标入画""黑水平带切入首帧"）。
5. 判声音：有人声 or 纯 BGM；给 BPM 区间 + 段落起伏 + 音效清单与卡点（转场音效对齐色块切入帧）；**显式写"全程不断无静音、峰值卡在 XX 秒的视觉奇观上、结尾淡出"（ce34）**。
6. **确认用户后期能力（涉及转场时必做，ce31）**：问"你有没有后期剪辑环节、工具支持首尾帧续写吗"。无后期 → 转场做成交付物本身（直接合成成品 MP4）或改用首尾帧续写；有后期 → 交规格表并明确写"需你手动叠"。不确认就默认用户会自己叠＝交付失效。
7. 按实测切点定位转场（ce32）：`fps=4` 抽帧拼图肉眼定切点，不按设计秒数；首尾帧续写则跳过此步但仍须给主角设定图。
8. 校验：每条包装都能回答"是什么类型、在哪、多大、怎么进、跟着哪句话"；纯 BGM 必须写"不要人声"；转场有无黑场已用 `blackdetect` 与原片核对；合成遮罩的成品须逐帧验峰值帧全盖、无黑场、无白亮斑、无残影。

**输出契约**
- 包装规格表（表格，含转场独立行）。
- 声音方案：人声策略 / BPM 区间 / 段落起伏 / 音效清单与卡点。
- 常驻图层清单（整段叠一次，不进逐镜）；落款固定为「环球数字文旅」。

## B — 边界

- **不要用**：无包装的纯视觉概念片（仅结尾标识）；用户要的是生成端文字（应改为后期叠字）。
- **作者警告的失败模式**：包装过密遮挡主体（ce11，素材中有 279 层/110 秒的极端案例）；纯 BGM 误加人声（ce12）；BPM 当确定值卡点（ce18）；把转场只写进规格表就当交付、未确认用户有无后期环节（ce31）；按设计秒数而非实测切点叠遮罩（ce32）；音轨出现静音窗、峰值没压在奇观上导致成片显平（ce34）。
- **反例速查**：本卡引用的 `ce` 编号见能力包根目录的 `resources/case-index.md` 末节「反例索引（36 条）」，一句话教训 + 证据等级；16 条是实测（`field-tested`，含 ce26–ce36 用户付费生成实测与成片/原片复盘反馈），其余为文档明示或推断。
- **作者盲点**：包装密度与完播率的关系未验证；"层数越多越热闹"是行业惯性，不是证据。
- **易混淆**：`prompt-pack`（生成画面，不含文字）；`deconstruct`（测量原片包装层）。
- **共同纪律**：七卡共用一套判定纪律（先测量后动笔 / 结构先定 / 分层不混 / 结果可复核 / 缺料走降级 / 证据分级 / 出彩可指认），全文见 SKILL.md「核心原则」；本卡只展开本域，跨域冲突以那 7 条为准。
