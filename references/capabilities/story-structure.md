# 叙事结构选型与分段节奏

## R — 原文

> "结构是「一个人 + 一座省的物产清单」……先用反差钩子抓注意，然后用「体育—生态—历史—科技—美食」五连击把四川的资源做成快节奏清单，最后落账号引导。每段都给一个具体画面证据。"
>
> —— `01_四川/拆解视频的提示词.md` §一

> "**一句话结构**：用「玻璃球里的广西」开场立住 AI 概念 → 超现实山水主视觉 → 老电视墙做复古转场 → 城市车行 → 按城市/主题快速过一遍广西 → 玻璃球与「广西」字样收束 → 账号引导页。"
>
> —— `12_广西/拆解视频的提示词.md` §一

## I — 自述

先判"资源是宽还是窄"，再选结构，最后排节奏；顺序不能颠倒。

- **资源宽且要覆盖全域** → 清单型（一人串场 + 五连槽，适合省级/城市形象片）。
- **资源窄但要讲透** → 单线叙事/探店型（一条街一门手艺，靠过程与人对谈）。
- **有强识别度造型** → 文物/静物复活型（馆藏多、造型辨识度高）。
- **有强轮廓的物产** → 超现实拼贴（汤变河、汤包长在树上、冰箱贴变实景）。
- **情绪优先、地标弱、20–30 秒** → 视觉诗（一字一镜）。
- **素材储备大、无主线** → 快剪扫城（靠地标密度与节奏）。
- **有本地人才懂的包袱** → 方言梗/武侠二创短剧（三拍：钩子 → 误会升级 → 包袱落地名）。

选定后必须写**分段表**：每段给"时间段 + 内容 + 镜头长度区间"。校验式：镜头数 × 平均镜头时长 ≈ 总时长；结尾必须有收束或转化位。

选型的硬要求：**能说出"为什么不是另一个结构"**。同一城市连做多条时要轮换结构——这是对抗同质化的唯一手段。

## A1 — 应用示例

**原片案例（结构族，均来自素材）**
- F1 一人穿城：`01_四川`（68.5s，五连槽）、`22_山西`（长版，按"夜景—美食—文创—古城—黄河—平遥—寺庙—大院—公路—博物馆"分段）、`02_南京`（探店七拍：悬念→地标→工坊→试戴→街巷→对谈→合影）。
- F2 文物复活：`06_三星堆`（44s）、`07_文物`（110s 横屏）、`26_故宫`（175s AIGC）。
- F4 极限快剪：`14_贵州`（38s 扫全省）、`17_贵州`（39s 高燃混剪，足球踢上天开场）。
- F5 物产超现实：`05_镇江`（汤变河）、`13_惠州`（动物+美食）、`08_四川冰箱贴`。
- 视觉诗：`16_酉阳`（一字一镜，25.7s）。
- 方言梗：`21_襄阳`（14.8s，青蛙叫法的包袱）。
- 武侠二创：`24_贵州`（35s 完整版）与 `25_河南`（17s 压缩版）——同结构不同信息密度。

**合成演练（非原片事实）**：目标是一个只有"一碗面、一座古桥、一处非遗作坊"的县城，30 秒、实拍为主。按本卡：资源不足 5 类 → 判定为单线叙事/探店，不套五连槽；分段为 0–3s 钩子（面汤沸特写 + 一句方言）、3–24s 过程（和面→上桥→作坊工序，每 5–6 秒换证据）、24–30s 收尾（人物在桥头吃面 + 地点字）。预期输出：一句话结构 + 3 行分段表 + "为什么不是清单型"的一句理由。

## A2 — 触发情境

**用户会在这些时候需要它**：
1. 手里有城市/主题/素材，问"这条片子该怎么拍、怎么排"。
2. 有一堆素材但没主线，纠结做清单还是讲故事。
3. 连续做了几条同类型片子，担心同质化。
4. 要向客户/领导解释"为什么选这个结构"。

**语言信号**：`这条片子怎么结构`、`用什么叙事`、`怎么分段`、`30 秒怎么排`、`拍成什么类型`、`how should I structure this video`、`narrative structure`、`story beats`、`shot rhythm`。

**与相邻能力的区分**：本卡只产出"结构 + 分段表"，不产出镜头级提示词（→ `prompt-pack`）；不负责换城市填充内容（→ `city-swap`）。如果用户已经指定参考片并要求 1:1 复刻，跳过本卡，直接进 `city-swap`。

## E — 执行

**输入契约（必需）**
- 主题类型（城市形象/单点非遗/文物/美食/剧情/情绪）。
- 可用资源清单（有几类、分别是什么）。
- 目标时长、画幅、制作方式（实拍/AI/混合）、是否要转化位（账号引导/搜索卡）。

**缺失处理**：资源清单缺失 → 先问"这个城市最能拿出的 3 个可视物是什么"；仍无 → 走推荐模板给 3 个候选结构，不空转。

**步骤**
1. 判资源宽度：≥5 类可视资源 → 清单型候选；≤2 类 → 单线/探店候选；造型识别度高 → 复活型候选。
2. 查 11 类结构表，选 1 主结构 + 1 备选；写出"为什么不是另一个"。
3. 定开场 3 秒钩子类型：反差（古人拿手机）、悬念（不露脸/一句话）、设定（玻璃球里的城市）、奇观（足球踢上天）。
4. 排分段表：段名 / 时间段 / 镜头长度区间 / 该段的画面证据。
5. 校验：镜头数 × 平均时长 ≈ 总时长；结尾有收束或转化位；连续两条片子结构不同。
6. 若资源缺口导致某槽无法填 → 明确写"换槽内容"或"降级为单线"，不硬凑。

**输出契约**
- 一句话结构（≤40 字）。
- 分段表：段号 / 时间段 / 内容 / 镜头长度 / 画面证据。
- 选型理由 1–2 句（含"为什么不是另一个"）。
- 风险提示：同质化、资源缺口、时长闭合。

## B — 边界

- **不要用**：客户已指定参考片并要求 1:1 复刻（结构不可改，只换槽）；纯素材剪辑已定剪、只需配文案时。
- **作者警告的失败模式**：所有城市都做成"一个人 + 五段物产清单"（ce19）；资源不足硬凑五连槽（ce05）；只换城市名不换地标（ce06）。
- **反例速查**：本卡引用的 `ce` 编号见能力包根目录的 `resources/case-index.md` 末节「反例索引（36 条）」，一句话教训 + 证据等级；16 条是实测（`field-tested`，含 ce26–ce36 用户付费生成实测与成片/转场/原片复盘反馈），其余为文档明示或推断。
- **作者盲点**：选型表来自 27 条抖音样本，横屏/中长视频的结构未覆盖；"结构雷同会被算法降权"是推断，素材无数据证明。
- **易混淆**：`deconstruct`（从成片反推结构）；`prompt-pack`（把结构写成镜头提示词）。
- **共同纪律**：七卡共用一套判定纪律（先测量后动笔 / 结构先定 / 分层不混 / 结果可复核 / 缺料走降级 / 证据分级 / 出彩可指认），全文见 SKILL.md「核心原则」；本卡只展开本域，跨域冲突以那 7 条为准。
