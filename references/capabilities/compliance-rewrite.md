# 合规改写（禁用词 + 客观化三步）

## R — 原文

> "**客观化改写原则**（三步）：1. **主观评价 → 可验证的事实**：「风景绝美」→「海拔约 4000 米的雪山与高原湖泊」；「最美的古城」→「青石板路、木结构楼房的古城街道」。2. **程度副词 → 画面中可见的元素**：「震撼的青铜器」→「青铜面具特写，绿锈与纹路清晰」。3. **排名 / 极值 / 承诺 → 删除或改中性描述**：「必去的网红打卡地」→「游客举手机拍照的街区」。"
>
> —— `01_四川/拆解视频的提示词.md` §0.1 合规红线

## I — 自述

这不是"润色"，而是一次**可判定的替换**：先按四类扫词，再按三条规则改写，最后复检每句是否"镜头里看得见"。

<!-- exempt-start 理由：禁用词清单是词表，必须与源文档列举逐词一致才能用于扫描；这是枚举引用，不是叙事照搬 -->
四类禁用词：
- **极值/排名**：最、最好、最佳、最强、最美、最火、最全、第一、首选、唯一、独家、首创、顶级、极致、巅峰、天花板、领跑、冠军、王牌。
- **绝对化**：国家级、世界级、宇宙级、绝无仅有、空前绝后、史无前例、100%、绝对、保证、永久、万能。
- **主观夸大**：震撼、惊艳、绝美、完美、无敌、神级、封神、YYDS、一生必去、必打卡、打卡圣地、网红圣地。
- **功效承诺**：必去、必买、包你、一秒穿越、立马见效、销量第一。
<!-- exempt-end -->

三条改写规则：主观评价 → 可验证事实；程度副词 → 画面里可见的元素；排名/极值/承诺 → 删除或中性化。

两个关键细节：
1. **作用域**：原片台词、歌词、画面原有文字属于客观记录，不改；只改"你自己撰写的"提示词、字幕、花字、口播稿、包装文案。
2. **防机械替换**："最"字不能全局替换——"最后""最近""最初"会被改坏。必须按词边界判断（如"最"独立成词或被"的/美/好"紧跟），并逐条人工确认。

合规句要写进**提示词本体**（"画面只用客观、可验证的描述；不使用夸大、绝对化或排名类词语"），而不是只写在文档说明里——否则模型仍会自由发挥。

## A1 — 应用示例

**原片案例（01_四川 §0.1）**：素材给出的三组改写对照——"风景绝美"→"海拔约 4000 米的雪山与高原湖泊"；"震撼的青铜器"→"青铜面具特写，绿锈与纹路清晰"；"必去的网红打卡地"→"游客举手机拍照的街区"。作者同时说明"台词、歌词、画面上原有的文字不在本规则范围内"。

**合成演练（非原片事实）**：输入"最美古镇，世界级非遗，必打卡，一秒穿越回宋朝，绝对不虚此行"。
- 命中：极值（最美）、绝对化（世界级）、主观夸大（必打卡）、功效承诺（一秒穿越、绝对）。
- 改写结果："青石板街与木结构楼房的古镇；列入非遗名录的某项技艺；游客在牌坊前拍照；穿宋制服饰的演员走过街口。"
- 复检：每句都能回答"镜头里看得到什么颜色/材质/位置/动作" → 通过。

## A2 — 触发情境

**用户会在这些时候需要它**：
1. 给官方文旅号/政务号/品牌方写文案，担心"最""第一"过不了审。
2. 提示词里写了"震撼大片感"，生成结果不稳定，想知道怎么改。
3. 客户/领导给的文案里有大量形容词，要落成可拍的画面描述。
4. 交付前做最后一遍合规检查。

**语言信号**：`这句话能发吗`、`会不会违规`、`禁用词`、`改成客观描述`、`广告法`、`去夸大`、`compliance check`、`remove absolute claims`、`objective rewrite`。

**与相邻能力的区分**：本卡只改文案与提示词的措辞，不改结构（→ `story-structure`）、不改槽位（→ `city-swap`）。它常被另外三张卡在最后一步调用。

## E — 执行

**输入契约（必需）**
- 待检查文本（提示词/字幕/花字/口播稿/包装文案）。
- 作用域确认：是否包含原片台词（台词默认不改）。

**缺失处理**：只有一句话也可执行；若用户要"保证过审"，明确告知本卡只做词表与客观化检查，不替代平台审核与法务。

**步骤**
1. 四类扫描，输出命中清单（原词 / 类别 / 位置）。
2. 按三条规则逐条改写；改写后必须仍能回答"镜头里看得到什么"。
3. 防误伤检查：单独处理"最后/最近/最初/最终"等含"最"的普通词。
4. 把合规句写入提示词本体（若交付物是提示词）。
5. 交付：改写后全文 + 命中清单 + 前后对照 + 一句"未改动原片台词（如适用）"。

**输出契约**
- 合规版全文（可直接使用）。
- 命中表：原词 / 类别 / 改法。
- 复检结论：是否每句可被镜头验证。

## B — 边界

- **不要用**：纯个人情绪表达、二创玩梗（合规句可保留但不必逐句改写）；原片台词转录（属于客观记录）。
- **作者警告的失败模式**：只查提示词不查包装层（ce03）；单字"最"机械替换改坏"最后"（ce02）；提示词自带夸大词却以为写在说明里就没事（ce01）；AIGC 标识缺位（ce04，本卡只提示，不给法规结论）。
- **反例速查**：本卡引用的 `ce` 编号见能力包根目录的 `resources/case-index.md` 末节「反例索引（36 条）」，一句话教训 + 证据等级；16 条是实测（`field-tested`，含 ce26–ce36 用户付费生成实测与成片/转场/原片复盘反馈），其余为文档明示或推断。
- **作者盲点**：只覆盖广告法意义的"绝对化用语"，不覆盖民族宗教、地图边界、历史表述等更敏感的合规领域——这些必须另行审查。
- **易混淆**：`story-structure`（换结构不是换词）；`city-swap`（换城市内容）。
- **共同纪律**：七卡共用一套判定纪律（先测量后动笔 / 结构先定 / 分层不混 / 结果可复核 / 缺料走降级 / 证据分级 / 出彩可指认），全文见 SKILL.md「核心原则」；本卡只展开本域，跨域冲突以那 7 条为准。
