## I — 自述

一套可直接投喂生成模型的提示词，由四个部件拼成，缺一个就不完整（有参考图时还有第五个条件部件）：

1. **全局前缀**：画幅/帧率 + 风格 + 色调 + 景深 + 主角 + 场景质感。语序固定，每段都要重复带（模型不记忆上下文）。
2. **镜头句**：按生成单元（G1…Gn）写，一句一个动作，包含景别 + 机位 + 运镜 + 主体动作 + 环境。**一个单元 1–4 个镜头，单次 ≤15 秒**，超了优先在换场景处切开，禁止在连续动作中间切。
3. **负向约束**：四段式——① 固定合规句（客观描述、不用夸大词）② 画面污染（不要字幕/水印/logo/台标）③ 主体失真（不换脸/不变形/不低清）④ 题材专属（文物"不要造型失真、碑刻乱码"；食物"不要菜品变形"；虚拟人"不要飘带穿模"；古装"不要现代物品/游客正脸"）。
4. **双版本**：每个单元给"模板版（`{{占位符}}`）"与"本片示例版（原值）"，两版句式与镜头顺序必须完全一致，差异只允许出现在槽位处。校验方式：把模板版的占位符用示例版的值代回，应逐字还原。
5. **图文配比**（条件部件，仅输入含参考图/三视图时启用；纯文生视频跳过）：参考图与文字要在**服饰、道具、姿态、场景**四栏逐项对齐。冲突时模型不报错、不询问，静默取舍的实测顺序是——**外观跟图、场景跟词、动作跟图的姿态**。三视图能锁住脸和衣服，但**同时锁死了身体姿态**：四张直立站姿喂进去，出来就是站着转头，哪怕镜头句写着"边走边说"。要动作，给视频参考或给一张动作姿态图，靠形容词无效。

特定题材另有构造法：**文物/静物复活**＝选件（造型辨识度高的 5–8 件）→ 给现代动作（逛街、喝奶茶、开演唱会）→ 场景串联 → 收在"全家福"；**超现实物产拼贴**＝保留物产轮廓，只换尺度或环境（汤变河、汤包长树上、冰箱贴变实景）。

**七种高翻车写法纪律（field-observed，2026-11-24 四轮 + 2026-11-25 云南水墨片首轮，实测反推）**——原书未覆盖，实测补：

1. **剪纸/剪影/版画风**：禁用「线稿」「描边」「白描」「速写」这类词——「黑白线稿剪影 + 粗描边」自相矛盾，模型执行「线稿」生成写实白描，五官、衣纹、渐变全冒出来。正确写法＝「**纯黑或纯白的实心剪影色块，没有线条/描边/纹理/五官/衣纹/投影/光影/立体透视**」；底色必须写「**满幅纯色铺满每一帧，不是白底/米白底/浅灰底，没有渐变/天空/留白边框/上下红条卡片式排版**」，否则模型自加米白底与卡片式留白。首轮实测：v1 写「线稿剪影」→ 古街变米白底写实线稿+行人、山水变渐变天空+祥云、对望变有五官胡须的工笔白描；v2 改成实心色块+满幅红底后画风对齐。（见 `01_四川` 之外的 2026-11-24 浙江→深圳换城案例）
2. **转场形态**：禁止只写「斜切遮罩」「闪黑」「转场」这类笼统词——实测模型执行成普通黑三角压入或溶解，和原片不符。写法＝**逐帧实测原片转场，拆成可数的三步几何动作**（第一步什么色块从哪切入把画面怎么分、第二步色块怎么变形、第三步怎么扫过、末帧定格成什么分割），并明写**不要什么**（不做全黑场、不做渐隐渐显、不做溶解）。「转黑 X 秒」是明确的闪黑指令，会造出原片没有的全黑场——原片若 blackdetect 无命中就绝不能写这句。转场必须同时列入包装层独立项（见 `packaging-audio`），否则只在镜头句末尾一句话里，生成端权重过低做不出来。**末帧要单独约束**：三步写完仍要补一句"某元素在片段结束前必须完全扫出画面、末帧不留残影"——实测写在段末的转场起步晚，末帧扫描线还卡在画面中央。首轮实测：v4 写「红黑斜切遮罩…转黑 0.5 秒」→ 生成黑三角+全黑 0.6s，而原片是红黑几何色块三段对切、全程无黑场；赛博线框片写「扫描线扫出画外」但没写"末帧前必须扫完"→ 末帧仍留竖线。

3. **自定义主角（机器人/数字人）**：只写正面特征（"流线型面罩无五官"）不够，模型会按类型先验补细节——实测机器人长出了面罩两侧的同心圆"耳机"盘。写法＝**正面定义 + 反向排除**成对写：「只有 X 造型，没有 A / 没有 B / 没有 C」（如"头部只有平滑面罩，没有耳机、耳罩、圆盘状结构、同心圆装置"），并把同一句反向排除写进负向第③段（主体失真）。多段连续的主角，定义块每段开头重复带保一致（模型不记忆上下文）。首轮实测：2026-11-24 南山AI漫游 G1，主角块只写"流线型面罩"→ 长出两个同心圆大圆盘；补反向排除后部分改善（有的段消除、有的段仍有）。
   **跨段一致性不能只靠文字**（实测 material-defect）：多段独立生成时，文字定义只约束"语义特征"（白色/青色/面罩/核心），锁不住"具体造型"——南山AI漫游 5 段生成出 3 款机器人（白色实心款/深色瘦款/线框镂空款），切点处造型断裂。根治＝**给一张主角正面设定图作参考图（reference_images），每段都带同一张锁外观**；场景仍靠文字。文字重复带只能保"同类角色"，保不了"同一个角色"。

4. **技术参数不进提示词**：分辨率/帧率/时长写进提示词，模型**不执行**（只影响语义，不影响编码）。实测写「1280×720、30fps、6.0s」→ 实际输出 1344×768 / 24fps / 6.58s。这些必须在画布/工具的参数栏锁，提示词里保留只是意图声明；验收时对不上的参数不算提示词漂移，不要回头改画风措辞。
5. **转场手法优先级（完整原片复盘后重排，ce33/ce31，field-tested 2026-11-25）**：
   - **先拆原片手法，再选写法**——不要跳过拆解直接套"墨晕遮罩模板"。拿到参考片先用 `fps=8` 逐帧看每处转场到底是"主体飞出画面"、"纹样形变"、"内容自身的墨盖满"还是"硬切+暗场"。**原片 7 处转场无一处用通用墨色洇入遮盖**，我之前正是用原片没有的手法模拟观感，越调越不像。
   - **①形变衔接（首选，最丝滑）**：写"**A 的某形态延展/化生成 B**"而非"A 切到 B"——鸬鹚翅膀越展越大化为远山轮廓、壮锦纹路拉长化作飘带、绣球炸开成墨花、墨花散处白纸显出字生出来。观众看到的是"一个东西变成另一个东西"，形变句必须写进**同一生成单元**（或首尾帧续写让末帧形态=下段首帧形态）。
     **拆到可数步骤（借鉴 rea-video 关键帧分类，2026-11-25）**：用户"不丝滑"的根因是形变只写一句"A 化成 B"，颗粒度太粗。写进提示词时至少覆盖其中 4 类关键帧：①**首帧**（A 初始形态：白鹭立于船头）②**动作开始**（形变启动：鹭翼向两侧展开）③**转折**（A→B 转换帧：翼的轮廓化作山脊线）④**元素出入**（鸟身淡出、山影渐显）；有余量再加**动作到位**（翼展至最大）、**构图变化**（鸟飞离方向即镜头上摇方向）、**转场中段**（此刻既像翼又像山，用于逐帧验收是否真形变）。每类一句话、带具体形态，不写"流畅过渡"这种空词。
   - **②主体连续运动带出**：让主体自己走出/飞出画面，新场景自然露出（鸟飞远→群山显现），比任何遮盖都自然。
   - **③首尾帧续写**（工具支持时）：上段末帧作下段首帧参考图，保衔接不保主角一致性（同主角仍须同一设定图）。
   - **④墨晕遮罩 = 无后期时的兜底遮丑**（ce31/ce32）：仅用于已生成片返工、且用户无后期环节时，把硬切藏进满墨帧；**不要当成正解**，它只能减轻硬切感、做不出原片的形变丝滑。
   - **分段独立生成的固有限制**（material-defect）：每段末帧不知道下段首帧长什么样，把转场写在段末模型只在自己段内脑补"新场景"，拼接必硬切（南山 4 处、云南 3 处全中）。**写在 packaging 段的转场不会自动进成片**——云南片三处边界全硬切就是后期漏叠；且切点会错位（设计 2.9s 实测 4.0s），兜底遮罩须按**实测切点**对齐。
   - **scene 检测有盲区**：色调相近的硬切 scene 0.3 都检不出，必须 `fps=4~8` 肉眼逐帧看段边界，不能只凭工具数字判"无硬切"。
6. **文化工艺名会被实体化为道具；「待后期叠加 XX 字」是矛盾指令**（ce26 / ce27，field-tested，2026-11-25 云南水墨片首轮付费生成）：写"山体浮现白族扎染的几何纹样"，模型把工艺名 concretize 成**一只手托着蓝白扎染球、球体滴墨**的实体物件，原片和提示词都没有；同轮 G4 写「画面右侧留白**待后期叠加**「七彩云南」书法大字」，模型无视"待后期"直接把字画了出来（且位置反了、字高只有期望的 2/3）。两条规避：①**纹样写成平面属性**——"表面有一层蓝白点状纹样，像印上去的平面纹理，不是实体物品"，并在负向④禁"手/手指/球体/圆形工艺品/扎染制品实体"；②**要后期叠字，生成端连字串都不能出现**——只写"留白，无文字"，字串一旦出现在提示词里模型就会画。同类风险：任何"XX 纹样/XX 工艺/XX 符号"都可能被实体化。
7. **同一生成单元里"水面"意象会压过"山巅"，要人物在高处就拆单元**（ce28 / ce29，field-tested，2026-11-25）：G4 同段先写"墨滴砸进水面炸开成山水画卷"、后写"女子立于山巅"，落地时人物被放到**水边石岸、侧背对镜头**，山巅功能位丢失。原因是一段内两个强场景意象互相覆盖，后者权重被前者压过。规避＝把"水面炸墨"与"山巅立人"拆成两个独立单元，且人物单元里不出现水，补"背景是云海与层叠远山，不站水边、不背对镜头"。

8. **写意画风里不要把人物肢体（脚/手）当主体特写**（ce35，field-tested，2026-11-25，用户原话"脚点水的画面很丑"）：写"赤足踩水"作主体，模型画出两条惨白写实小腿从木船伸出、插画皮肤质感，水波变成两个规整白色同心圆，与周围水墨写意完全撕裂；原片同位置只是水墨几笔的脚 + 自然扩散的涟漪，融在青绿里。规避三选一：①**不写脚，只写效果**——"水面泛起涟漪，有人涉水而过"（全身/远景/剪影）；②必须局部时，明写"水墨几笔勾出、与山水同色、无写实皮肤与趾甲细节、涟漪自然扩散非同心圆"；③给一张风格一致的参考图锁画风。**通则是：风格越写意，越不能把暴露的人体局部当画面主体**——模型画人体默认走写实先验，一写局部就破功。

**生成后验收（有回传生成视频时必做）**：抽 0.5s 间隔拼图逐帧对比原片，核底色、画风、五官、转场形态；用 `blackdetect` 核对黑场有无与时长，用 `scene` 检测核对硬切数。发现漂移时回到自己写的提示词逐句找触发词（哪个词导致写实、哪个词导致黑场），改词而非改参数。「无原片的设计驱动型交付」同样要验收，只是基准从"像不像原片"换成"是否达成设计意图 + 有无类型先验污染"。

## A1 — 应用示例

**原片案例（01_四川，G1–G6）**：全片 14 镜被压成 6 个生成单元，每单元 1–3 镜，均给双版本。G1（0–10.1s）镜头句为<!-- exempt-start 理由：引用原片 G1 原句作案例，逐字保留才能说明"原句长什么样" -->"唐代书生举着手机自拍，边走边对镜头说话，背景是青城山雾气与竹林，竖屏自拍视角，轻微手持晃动"<!-- exempt-end -->；G2 用"红色背景上金色 2026 HAPPY NEW YEAR 字样，烟花与光斑，闪白转场"做节拍插入。负向块每单元重复一次。

**原片案例（26_故宫，G1–G11）**：175 秒 AIGC 长片被切成 11 个生成单元，其中 G10 原为 41.6 秒，按"换场景处切"拆成 3 次生成——这是"超模型时长必须拆"的实证。

**实测案例（本人三视图 + 01_四川 G1，2026-11-23，field-tested）**：输入为四视角棚拍三视图（交领道袍 + 山水折扇 + 直立站姿）+ 原片 G1 镜头句「举着手机自拍，边走边对镜头说话，轻微手持晃动」。输出 11.04 秒 / 480×854 / 24fps / 单镜头零切点。结果：服饰领型完全还原（交领）、竹林雾气到位，但**手机没出现、没有行走、手持晃动反而变成稳定缓推**——视角/道具/动作/机位四重指令，只有静态部分被执行。补测口播层（8 fps × 16 格嘴部）：**嘴唇全程闭合，无一次张口**，音轨只有 −45 dB 底噪。用户当时的真实诉求是"人对着镜头讲话"，不是"举手机自拍"——这两件事要分开验收，见 E 段「口播镜头单独判定」。

同轮还踩了一个诊断坑：先把「圆领袍」生成成交领判为形制错误，实际**参考图本身就是交领**，模型是忠实还原。教训是**图词冲突时先看图，别先改词**——改词改了也无效，因为外观归图管。

**合成演练（非原片事实）**：给定"4 段 / 12 镜 / 60 秒"的结构与槽位表，模型单次上限 10 秒。按本卡切出 G1–G5（每段一个单元），每单元 ≤10 秒；G3 因跨两个场景被切成两次；负向块按"人物 + 古建"补第 4 句"不要改变斗拱、匾额、屋顶形制"。预期输出：5 个单元 × 2 版本 + 1 份负向块。

## A2 — 触发情境

**用户会在这些时候需要它**：
1. 结构已定，要把它变成能直接复制到生成工具里的提示词。
2. 手上有一份别人的提示词，想改成自己可用的格式（双版本 + 负向）。
3. 生成结果老出问题（画面里冒字幕、脸变形、文物被改），需要补负向约束。
4. 要估算生成成本（几个单元 = 几次调用）。

**语言信号**：`写分镜提示词`、`生成提示词`、`把结构变成 prompt`、`分镜怎么写`、`负向提示词`、`write shot prompts`、`storyboard prompts`、`negative prompt`、`image-to-video prompt`。

**与相邻能力的区分**：本卡不选结构（→ `story-structure`），不做换城填充（→ `city-swap`），不做合规审查（→ `compliance-rewrite`，但本卡内置了合规句）。若用户只说"帮我把这条片换成我们城市"，直接进 `city-swap`，不必重写提示词。

## E — 执行

**输入契约（必需）**
- 结构 + 分段表（来自 `story-structure`，或用户给定）。
- 槽位表（来自 `city-swap`，或本卡现场建）。
- 生成模型单次时长上限（默认 10 秒；未知则按 10 秒保守处理）。
- 画面基准（景别配比/机位/光比/色温/调色/刀数），无则标"估算"。

**缺失处理**：无画面基准 → 只写结构与镜头句，不写"精确参数"，并在交付中标"参数为估算"。

**前置检查（输入含参考图/三视图时必做，不做则整轮生成白跑）**

把参考图与提示词摊在四栏上逐项对，任一行冲突就先改一边，再开始写：

| 栏 | 查什么 | 冲突后模型的静默取舍 |
|---|---|---|
| 服饰 | 形制、领型、袖宽、腰带、鞋 | 跟图走，文字白写。若图错了就先改图，写词改不动 |
| 道具 | 手里拿什么 | 图和词各写一个 → **两个都不出现**，手空着 |
| 姿态 | 站 / 走 / 坐 / 卧 | 跟图走。图是站姿 → 生成就是站姿，动作词全部失效 |
| 场景 | 背景环境 | 这一栏**词优先**，图的白背景会被替换 |

姿态栏最容易漏，代价也最大。三视图是"人物一致性"的最佳输入，同时是"动作驱动"的最差输入——它把身体钉在拍照那一刻。

要动态有三条路，**A 与 B 各有实测，按"要不要复刻现成动作"选，不按强弱排序**：

- **A. 按生成单元切短（3–13s）+ 提示词写具体动词与宾语 + 后期拼接**——已实测有效：68 秒成片 7 个槽位落地 5 个，6 处单元边界里 5 处切点误差 ≤0.03s。**换城、换人、自造镜头只能用这条**。
- **B. 给视频参考（视频转视频）**——**已对照成立**：同一镜头（G1 自拍 + 边走边说）无参考视频 7 项过 3 项（A：3/7），加参考视频 6 项过 6 项（B1：6/7，仅场景项因跟了参考片而记警示）。两条片子参数不齐（480 vs 736 宽）、单样本，不是纯净单变量实验，但行走与道具是"零到一"的差别，主因判为参考视频。机制与四个坑见下。
- C. 给动作姿态图当首帧——**未测**。

**B 路真正借到的是"段落编排"，不是运镜。** 参考片的顺序是「自拍开场 → 指镜头 → 转身走 → 举手机拍前方」，成片四步对四步。前两轮把同一镜头写成"自拍 + 边走边说 + 手持晃动"三个并列形容，模型不知道先干什么后干什么；参考视频把时序直接给了它。**所以要用 B 路，提示词里也要把动作写成先后顺序，别只写状态。**

B 路四个坑（均已实测）：

1. **场景会被参考片覆盖，优先级高于文字**。两轮提示词都写「青城山雾气与竹林」：无参考视频时生成竹林石阶，加参考视频后生成山脊草甸 + 城市天际线 + 海面（= 参考片场景）。**所以 B 路与换城互斥**——参考片是四川山脊，换城后出来还是四川山脊，等于没换。要换城，只能换一条目标城市的参考片，或退回 A 路。
2. **音频会被一起带过来**。成片后 6 秒音轨与参考片互相关 0.89–0.98（前 4 秒 0.03–0.10，是新内容）——不复制画面，但保留了参考片声音。发布前必须整轨替换，否则是别人的配乐或原声。
3. **规格由你自己选，选了非标值要留后手**。实测两次：一次画布默认给 480×854，一次手动设 736×1280/24fps（为省成本）。736/1280=0.575 不是 9:16，发布可能被裁切——成片阶段缩到 720×1280 再发。验收一律用 ffprobe，不看界面显示。
4. **口型是动作模仿，不是音频驱动**。成片 2.0–2.6s 有 3–4 次张口，但同期音量在下降，不同步。这说明模型是"看到参考片里的人在说话"，不是因为文字写了"说话"——**文字仍然不能让人开口**。

另一条独立结论：**机位关系类描述最难落地，但不是全丢**。实测写「举着手机自拍」且参考图里没有手机，出来的是**贴近正面的中近景、脸占画面高约 1/3、胸口以下出画**——构图已接近自拍，但没有手臂、没有手机、没有广角畸变，即"像自拍但拿不出持机证据"。所以判机位要分层：构图近不近（容易达成）／持机证据在不在（很难达成）。这类要求必须单独验收，别和动作混为一谈。**更前一步的问题是：参考图里若没有手机，「举着手机自拍」就是无源之词，不是难落地而是无从落地，应直接删掉。**

但这条**只对纯文字 / 纯参考图输入成立**。给了参考视频之后，同一个 G1 拿到了持机手臂、手持折扇与画内手机（7 项过 6 项，对照无参考视频的 3 项）——说明机位不是"模型不理解自拍"，而是"它没有可以抄的对象"。所以处置顺序要改：**想让机位与连续动作成立，先给参考视频；没有参考视频，就别在文字上死磕，直接改成第三人称方案。**

**口播镜头单独判定**。"对着镜头说话"是一句复合要求，实测（8 fps × 16 格嘴部密采样）证明它得拆成三件查：

| 部件 | 改提示词有用吗 | 做法 |
|---|---|---|
| 取景距离（口播须胸上近景） | **没用**，由参考图构图决定 | 换参考图。三视图是全身站姿 → 出来必然是七分身中景，脸只占 1/6 |
| 视线锁定镜头 | 有用，但要写成**姿态** | 写"双眼直视镜头"；不要写"对着镜头说"——后者是行为 |
| 嘴部开合 | **没用**，归音轨 | 需音频驱动 / lip-sync / 数字人成片。无音频输入时模型没有开口依据，实测 2 秒 16 格嘴唇全闭 |

所以分工会落在路径上，不在措辞上：**图生视频负责"人在景里"，台词交给配音或数字人。** 要"换装换人但保留口播"，参考图必须是正对镜头、胸上近景的素材，再配音频驱动，不能指望三视图。写形容词（语气、语速、说什么）在没有音频输入时全是无效字符。

**输入是参考视频时**（与参考图不同，另有四条要注意）：

1. **参考片本身必须是目标城市、目标场景**。参考视频会覆盖文字里的场景描述（实测：提示词写「竹林」，加了山脊参考片就生成山脊）。所以**参考片选错等于换城失效**，先确认参考片拍的就是你要的地方，再谈动作。
2. **先选对模式**。选"动作 / 运镜参考"，不要"风格迁移 / 内容重绘"——后者会把参考片里的文字、场景、人物一起画进来，等于白换。
3. **参考片的字幕、台标、新闻标题会被复制**。原始素材往往叠满文字（实测一条 10 秒参考片：顶部标题占 18% 画面高、左右各一条竖排、底部字幕、右下台标）。负向要写"不要生成任何文字、字幕、水印、台标、logo"，**不要列举具体字符串**（把"某某草堂""AI某某"写进负向，部分模型反而会画出来——此条属推断，实测未做对照）。
4. **别自己去做去字预处理**。`delogo` 在这类大面积文字上用周围像素插值，把人物拉成竖条，比带字更糟（已实测失败）。宁可留着原字、靠负向压制。

参考视频的时长要与目标镜头对齐（差 0.1 秒以内），并在首行只借"机位 / 景别 / 人物动作 / 运镜节奏"，不要照搬原书那句"照它的分镜数"——那是给整片 14 镜写的，用在单条 10 秒上会让模型硬塞多个镜头。

**步骤**
1. 写全局前缀：画幅 + 帧率 + 风格 + 色调 + 景深 + 主角 + 场景质感 + 合规句。完成标准：去掉任一要素，画面会明显漂移。
2. 切生成单元：按分段表合并连续镜头，单次 ≤ 上限，切点落在场景边界。完成标准：单元时长总和 ≈ 总时长；无单元超限。
3. 逐单元写镜头句：景别 + 机位 + 运镜 + 主体动作 + 环境。完成标准：每句都能被"镜头里看得到什么"验证。
4. 写负向四段式，第 4 句按题材补。完成标准：四类各 ≥1 条，题材专属条来自本片真实风险。
5. 出双版本，做代回校验。完成标准：两版可 diff，差异只在槽位。
6. 标注调用次数（= 单元数）与预估成本。

**输出契约**
- 全局提示词（模板版 + 示例版）。
- 生成单元表：G 编号 / 镜号区间 / 时间段 / 时长 / 镜头句（双版本）/ 负向块。
- 负向约束块（可复制）。
- 单元数与调用次数统计。
- **复制即用版文件**（user-specified，2026-11-26）：同目录 `生成用_可直接复制_<版本>.md`，逐单元把全局前缀 + 主角块 + 镜头句 + 负向展开拼成整段可复制的 text 块，零占位符、零 `[全局前缀]` 标记；md + json 是规格文档，不是生成输入。缺此文件视为交付未完成。

## B — 边界

- **不要用**：全实拍项目（应写拍摄场次 S1/S2 与现场布光，而非生成提示词）；模型已支持长时长单次生成时，不必强行按 15 秒切；纯文生视频时不要套用图文配比检查（没有参考图，四栏无从对起）。
- **作者警告的失败模式**：生成端出字幕/水印导致双重文字（ce10）；跨镜人脸不一致（ce08）；单元超时长上限（ce13）；竖屏号照抄横屏模板（ce09）；示例版残留占位符（ce07）。
- **反例速查**：本卡引用的 `ce` 编号见能力包根目录的 `resources/case-index.md` 末节「反例索引（36 条）」，一句话教训 + 证据等级；16 条是实测（`field-tested`，含 ce26–ce36 用户付费生成实测与成片/转场/原片复盘反馈），其余为文档明示或推断。
- **实测失败模式**：参考图的站姿压制提示词的动作，四重指令只落地静态部分，道具被整个丢弃（ce25）；**写"对镜头说话"不会让嘴动——无音频输入时口型不生成**（ce25 第二失效面）；按单元生成时若单元内不做切分，每段一镜到底，节奏会明显慢于原片——15 秒是模型上限，不是节奏上限；**加参考视频能救回机位与动作，但会把参考片的场景与音轨一起带过来（写"竹林"出山脊；后段音轨互相关 0.89–0.98），规格是自己选的、非标值需后期归一**。
- **作者盲点**：提示词写法绑定 2026 年模型能力（文字易乱码、主体一致性差）；"写得越细越好"未验证，过长提示词可能反而降低稳定性；**原书全程假设纯文生视频，没有讨论参考图与文字的冲突**——这一整块是实测补的，四条规律已写入上文 I 段第 5 条与 E 段前置检查。
- **易混淆**：`deconstruct`（测量原片）；`city-swap`（只替换槽位）；`packaging-audio`（字幕/花字/配乐是后期层，不让模型生成）。
- **共同纪律**：七卡共用一套判定纪律（先测量后动笔 / 结构先定 / 分层不混 / 结果可复核 / 缺料走降级 / 证据分级 / 出彩可指认），全文见 SKILL.md「核心原则」；本卡只展开本域，跨域冲突以那 7 条为准。
