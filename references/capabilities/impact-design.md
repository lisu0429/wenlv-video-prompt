## I — 自述

**这套技能此前是纯防守体系**（29 条反例、烧钱前预检清单全在教"怎么不翻车"），缺了"怎么出彩"这一半。结果是交付默认形态「安全但平」——用户付费生成后的反馈原话：「你给我的提示词做出来的视频都太平淡了」（field-observed，2026-11-25，沉淀为 ce30）。本卡补的就是这一半。

**第一纪律：合规的"客观"只约束内容，不约束节奏。** 「客观呈现、不使用形容词与夸大/绝对化词」禁的是**吹牛**（最美/第一/必去），不禁**速度变化、剪辑密度、形态突变、视觉奇观**。把两者混为一谈，把"客观"写成"缓慢、平稳、无切镜"，是把片子写平的头号根因。反例：`云南水墨复刻` v1 全局前缀写「镜头运动缓慢、以推和缓慢横移为主」，4 个单元句尾全写「全程无切镜」，声音写「6.6–14.7s 节奏平稳」——20 秒成片一条平线，高潮段被自己写死。

**第二纪律：结构锁死 ≠ 节奏锁死。** city-swap 的「只改变量、不动结构」锁的是**镜头顺序、景别配比、镜头数、总时长**，不是锁速度曲线。逐帧复刻必须连**爆点、速度差、形态突变**一起复刻——原片凭什么好看就凭什么复刻。把原片的"墨滴炸开成山水"写成"墨迹缓缓晕开"、把"极限快剪段"写成"节奏平稳"，这是**复刻失真**，不是忠实原片。

**三件可检查的出彩件**（不靠形容词，靠画面本身）：

1. **速度差**：一条片子至少有「慢—快—收」三段强度变化，不是全程一个速度。手段：某段插 0.3–0.8s 极短镜、连续同景别三连切、慢镜后突然回常速。**写在提示词里**就是给该单元写「镜头由缓推转为快速横移，末 0.5s 定格」，而不是全片「缓慢」。
2. **形态/尺度突变**：局部瞬间变整体、实物变超现实（墨滴→整幅山水、汤→河、冰箱贴→实景）。这是记忆点的主要来源，也是 27 条样本里出彩片的公共特征。写法必须给出**突变前的具体物**和**突变后的具体物**，不写"画面一转"。
3. **母题重复与变奏**：同一造型出现 2–3 次，第三次变形或反转（`12_广西` 玻璃球三现）。复刻时若原片有母题，必须列出它在哪儿出现、第三次怎么变；只换城市名会把母题一起丢掉。

**出彩不止在镜头层——还有两条平行的"平感"来源（ce33/ce34，field-tested 2026-11-25 完整原片复盘）**：①**转场形态**：原片 20 秒里 7 处转场全是形变衔接（鸟飞远→山、锦纹→绸带、绣球→墨花、墨→字），没有一处通用遮罩；形变形写好，"转场"本身就是出彩点；用遮罩盖只能减轻硬切、出不了彩。②**音轨能量**：原片 0 静音、峰值压在 15s 炸墨上；生成片 16.4% 静音、奇观段无声，画面再动也显平。**做张力表时把"形变转场"和"音轨峰值点"一起列进去**，别只列镜头速度——用户说"平"经常是这两条没做，不是镜头慢。

**有没有真的不平——用画面变化曲线自查（借鉴 rea-video rhythm 层，2026-11-25）**：张力表是"设计时"的意图，还需"交付前/验收时"的量化核对。抽帧算相邻帧灰度差，输出每 0.5 秒一位 0–9 的变化曲线：
```
ffmpeg -y -i V -vf "fps=2,scale=160:-1" frames/%03d.jpg
# numpy：逐帧读灰度，算相邻帧绝对差均值，归一化到 0-9
```
曲线连续 ≥3 位 ≤2 即判"平段"——和音轨 RMS 曲线（ce34）叠看：**画面平 + 音轨平 = 双重平**，不用等用户说"太平淡"就能自查出来。曲线还要看有没有明显峰值（对应视觉奇观），一条直线到尾即使不低也算平。

**负向预算**：四段式负向超过 ~200 字时，正向表现力会被稀释。检查每条正向镜头句是否至少有一个**具体动作或形态变化动词**（滴落/炸开/掠过/三连切/定格/骤停），通篇「呈现/有/是/静静/缓缓」即判平淡，须返工。

**「无切镜」不是每段默认句**：只有明确要长镜头时才写「本段一镜到底」；其余段落写清镜头**内部**发生的变化（速度/形态/光线/景别），别用一句「全程无切镜」把节奏焊死。

## A1 — 应用示例

**原片案例（素材事实）**：`09_广西` 墨滴砸进水里炸开成整幅山水（形态+尺度突变）；`05_镇江` 汤变河（超现实突变）；`12_广西` 玻璃球母题三现 + 63s 极限快剪段（速度差 + 母题）；`21_襄阳` 三拍包袱（钩子→误会升级→落地）。这些是原片自带的出彩件，拆解时必须被记进张力表，不能只记景别与时长。

**合成演练（非原片事实）**：`云南水墨复刻` v1 的 G3 原句「苍山层层叠起…洱海化作蓝色丝带，镜头缓缓横移」——8.1 秒最长段、节奏平稳，正是平淡主因。按本卡改：①写张力表；②G3 改「前三镜各 0.8s 短切：山脊线→扎染纹样特写→水带横扫（速度逐镜加快），第 4 镜慢下来定格在远山，末 0.5s 留白」——镜头数、总时长、结构位置都不变，只改速度曲线；③G2 补白鹭「展翅到一半定格 0.4s」的小爆点；④G4 炸墨保持原片的骤然爆发，不写「缓缓」。预期输出：张力表 4 行 + 每单元 1 条出彩点 + 一句"为什么不平淡"。

## A2 — 触发情境

**用户会在这些时候需要它**：
1. 用户看完生成片说「太平淡 / 没记忆点 / 不够燃 / 千篇一律 / 像PPT」。
2. 复刻一条参考片时，怕只抄了结构没抄到"好看在哪"。
3. 交付前自查——提示词全对但心底觉得"缺点什么"。
4. 同一城市连做多条，担心越做越平（与 story-structure 的"换结构"配合：结构换不了时，先换张力曲线）。

**语言信号**：`太平淡`、`没记忆点`、`不够抓人`、`不够燃`、`像流水账`、`像PPT`、`千篇一律`、`boring`、`flat`、`no hook`、`memorable`、`punch`、`wow moment`。

**与相邻能力的区分**：本卡不产出镜头句本身（→ `prompt-pack`），不改结构选型（→ `story-structure`），不负责换城填槽（→ `city-swap`）。本卡输出的是**张力表 + 出彩点清单**，作为提示词装配前的输入约束；若用户已明确说"平淡"，本卡与 `prompt-pack` 同时加载。

## E — 执行

**输入契约（必需）**
- 参考片的拆解数据（含速度/爆点证据）或待检查的提示词包。
- 结构分段表（时间段 + 镜头数），用于在不改结构的前提下排张力。

**缺失处理**：只有成片没有拆解 → 先按 `deconstruct` 量出速度变化与爆点位置；两者都没有 → 索要其一，不凭"应该燃"空写。

**步骤**
1. 先还原（或设计）张力曲线：给每个单元标强度 1–5 与手段，写出"爆点在第几秒、靠什么画面实现"。**没有爆点即判平淡**。
2. 出张力表：时间段 / 强度 / 速度或形态手段 / 画面证据 / 对应原片依据（复刻时）。
3. 逐单元检查正向镜头句：是否至少有一个具体动作/形态变化动词；是否误用「缓慢、平稳、静静、全程无切镜」把节奏焊死。
4. 检查合规句是否误伤节奏：把"客观、不用形容词"错写成速度约束的，改回"内容客观、节奏照曲线"。
5. 检查母题：原片有母题的，列出三现位置与第三次变形；复刻时丢了母题要补回。
6. 负向预算：四段式负向超 ~200 字时，确认正向句仍保有明显动作，不被负向压成静态描述。
7. 输出出彩点清单（至少 3 条）与一句"为什么这样不平淡"；命中 ce30 的写法逐条标出并改写。

**输出契约**
- 张力曲线表（4 行起：段 / 强度 1–5 / 手段 / 画面证据）。
- 出彩点清单（≥3 条，每条写明落在第几秒、靠什么画面）。
- 改写对照：平淡原句 → 改后句（不动结构、时长、镜头数）。
- 校验：`镜头数 × 均长 ≈ 总时长` 仍成立；禁用词仍 0 命中；命中 ce30 项数归零。

## B — 边界

- **不要用**：用户明确要"一镜到底、极简静观"的片子（此时平是风格不是缺陷，须先确认）；纯素材已定剪只配文案时。
- **作者警告的失败模式**：把"客观"写成"平稳"（ce30）；把"不动结构"执行成"冻结节奏"（ce30）；每段默认「全程无切镜」；全片通篇「呈现/有/是」无动作动词；用夸大词冒充张力（合规禁止，见 compliance-rewrite）。
- **反例速查**：本卡引用的 `ce` 编号见 `resources/case-index.md` 末节「反例索引（36 条）」；16 条是实测（`field-tested`，含 ce30"太平淡"、ce34 音轨静音致平、ce35 肢体写实撕裂；转场 ce31–ce33 见 `packaging-audio`/`prompt-pack`），其余为文档明示或推断。
- **作者盲点**：27 条样本里"速度差—记忆点—完播"的因果没有数据证明；本卡给的是**可检查的预防项**，不是"这样做就爆"的保证。用户要求"保证爆款"时按 SKILL.md「边界与判停」拒绝承诺。
- **易混淆**：`story-structure`（选结构/换结构，管"骨架不同"）；`prompt-pack`（装配镜头句，管"写得对"）；本卡管"好看在哪"，三者输出不可互相替代。
- **共同纪律**：七卡共用一套判定纪律（先测量后动笔 / 结构先定 / 分层不混 / 结果可复核 / 缺料走降级 / 证据分级 / 出彩可指认），全文见 SKILL.md「核心原则」；本卡只展开本域，跨域冲突以那 7 条为准。
