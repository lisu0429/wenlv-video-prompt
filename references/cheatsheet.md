# 决策规则速查 — 文旅短视频提示词蒸馏包（27 条文旅片拆解与可替换提示词）

| 能力 | 一句话规则 |
|---|---|
| 逆向拆解一条参考片 | 不写影评，把成片还原成十段式施工图：分镜表 + 画面基准 + 包装计数 + 声音参数 + 不确定项。 |
| 叙事结构选型与分段节奏 | 先判资源宽窄，再从 11 类结构里选一个，并写清「为什么不是另一个」与分段节奏。 |
| 提示词包装配（全局+分镜+负向+双版本） | 四件套装配：全局前缀 + 生成单元镜头句（≤15s）+ 负向四段式 + 模板/示例双版本；有参考图时加「图文配比」，人物需开口时加「口播三件套」，要复刻连续动作时加「B 路视频参考」（连场景一起借，与换城互斥）。 |
| 换城 / 换人 / 换场景 | 只改变量不动结构：三入口取素材 + 四步降级 + 五连槽换城 + 槽位表反查。 |
| 合规改写（禁用词 + 客观化三步） | 四类禁用词扫描 + 客观化改写三步 + 防「最后/最近」误伤 + 合规句写进提示词本体。 |
| 包装层与声音设计 | 包装八类规格表（含转场独立行、按台词锚点定位、常驻图层整段叠）+ 声音方案（BPM 区间、音效卡点、纯 BGM 禁人声）。落款固定「环球数字文旅」。转场先问用户有无后期环节：没有就把遮罩合成为成品交付（ce31），切点按 `fps=4` 抽帧实测定位（ce32）。 |
| 视觉张力与记忆点设计（反平淡） | 交付前出张力表（段/强度1–5/手段/画面证据）+ ≥3 条出彩点；把"客观"写成"缓慢/平稳/无切镜"= ce30；结构锁死≠节奏锁死，原片爆点/速度差/母题必须一起复刻。 |

**交付硬规则（每次必守）**：
- 提示词包必须同目录配套结构化 `prompts.json`，缺 json 视为交付未完成。
- **每次交付必须再出一份「复制即用版」`生成用_可直接复制_<版本>.md`**（2026-11-26 用户指定）：逐单元把全局前缀+主角块+镜头句+负向拼好，零占位符、零 `[全局前缀]` 标记，每段一个 text 块整段可贴；md 与 json 是规格文档，不能直接喂生成工具。
- 落款/署名/账号角标一律「环球数字文旅」，不用城市文旅占位、不带抖音号。
- 生成后实测验收：抽 0.5s 拼图逐帧对比底色/画风/五官/转场形态，结构时长对齐不等于画面像；漂移要回提示词找触发词。
- 用户回传视频＝一次付费实测：必须完成「逐帧验收报告 → 回提示词找触发词 → 写成 ce 编号回写 case-index + 能力卡」闭环，只交报告不回写＝本次付费白花。
- 交付提示词前必跑下方「烧钱前预检清单」18 项，命中即改词，不把已知坑留给用户付费去试。
- 交付必须列张力表 + ≥3 条出彩点（第几秒 / 靠什么画面）；只做到"不出错"而列不出出彩点＝ ce30 交付未完成。
- 涉及转场必先问用户有无后期环节：无后期就把遮罩合成进成品 MP4，别只交规格表（ce31）；切点按实测抽帧定位、不按设计秒数（ce32）。
- 剪纸/剪影禁写「线稿/描边」，写「纯色块实心剪影 + 满幅纯色底」；转场禁写笼统词与「转黑 X 秒」，逐帧实测后拆成可数几何步骤并列入包装层独立项，转场末帧补「扫出画外、不留残影」。
- 自定义主角（机器人/数字人）要写「正面定义 + 反向排除」（如"只有平滑面罩，没有耳机/圆盘"），排除句同时进负向；多段定义块每段重复带只能保同类，保不了同一个——跨段一致性必须给同一张主角设定图作参考图。
- 分段生成的转场别指望跨段衔接：每段独立生成、末首帧对不上→硬切。转场移交后期叠，或首尾帧控制；scene 检测有盲区（色调相近的硬切检不出），段边界必须肉眼逐帧看。
- 分辨率/帧率/时长不进提示词（模型不执行），在画布参数栏锁；对不上不算提示词漂移。
- 生成工具该贴哪个文件：贴「复制即用版」`生成用_可直接复制_<版本>.md` 中每段的 text 块；md 与 json 都不可直接贴（它们是规格文档，前缀标记与占位符未展开）。

## 烧钱前预检清单（交付提示词前必跑，逐项打勾）

> 用户拿提示词去生成是要付费的。下面每一条都对应一次**真实返工费用**（2026-11-24/25 本机四轮 + 云南水墨首轮实测）。交付前逐项自查，命中即改词，**不把风险留给用户去烧钱试**。

| # | 自查项 | 危险写法 | 正确写法 | 反例编号 |
|---|---|---|---|---|
| 1 | **工艺/纹样/符号名会不会被实体化** | 「山体浮现白族扎染的几何纹样」→ 生成一只手托扎染球滴墨 | 「山体表面有一层蓝白点状纹样，像印在岩石上的平面纹理，不是实体物品」；负向④补「不要手/球体/圆形工艺品/制品实体」 | ce26 |
| 2 | **有没有"待后期叠加 XX 字"的矛盾指令** | 「留白待后期叠加『七彩云南』书法大字」→ 生成端直接把字画出来（位置/字高还不对） | 生成端只写「留白，无文字」，**字串一个都不出现**；字全交后期叠 | ce27 |
| 3 | **同一单元里有没有两个强场景意象** | 同段先「砸进水面炸开」后「立于山巅」→ 人物被放到水边 | 拆成两个单元；人物单元里不出现水，补「背景云海与远山，不站水边」 | ce28 |
| 4 | **转场是否只写在 packaging 而没交代后期** | 包装层写了墨晕遮罩，成片三处边界全硬切 | 生成端删转场句 + 明确写「后期在 N 个边界叠」，叠点按**实测切点**对齐，不按设计时间 | ce29 / ce11 |
| 5 | **分辨率/帧率/时长是否混进提示词当执行指令** | 提示词写「1920×1080、30fps、20.4s」→ 输出 1280×720/18s | 画布参数栏锁；提示词数字只作意图声明，验收对不上不算漂移 | — |
| 6 | **换城时是否误用参考视频 / 未补原片专属负向** | 拿原片当参考视频→生成回原片场景；只换城市名→地标张冠李戴 | 换城走 A 路文字描述；负向④补「不要原片专属元素」（如竹筏/鸬鹚/喀斯特） | ce06 / ce21 |
| 7 | **自定义主角/剪纸画风的反排除句是否配对写全** | 只写正面特征→长出耳机盘；写「线稿剪影」→写实白描 | 正面定义 + 反向排除成对写；剪纸写「纯色块实心剪影 + 满幅纯色底」 | ce25 等 |
| 8 | **交付三件套是否齐（md + prompts.json + 复制即用版）、落款是否固定值** | 缺 json / 缺复制即用版（用户拿 md+json 直接贴，`[全局前缀]` 被当字面词喂进去）/ 落款写城市文旅占位 | 同目录必出 `prompts.json` 与 `生成用_可直接复制_<版本>.md`；复制版逐单元拼好前缀、零占位符零标记；落款一律「环球数字文旅」 | user-specified |
| 9 | **有没有把"客观"误写成"缓慢/平稳/全程无切镜"** | 全局前缀写「缓慢、以推和横移为主」、句尾全写「全程无切镜」、声音写「节奏平稳」→ 全片一条平线 | "客观"只约束内容不约束节奏；按 `impact-design` 出张力表，高潮段写明速度变化与爆点画面 | ce30 |
| 10 | **正向镜头句有没有动作/形态变化动词** | 通篇「呈现/有/是/静静/缓缓」→ 静态描述，无记忆点 | 每单元至少 1 个具体动作动词（滴落/炸开/掠过/三连切/定格/骤停），并写出突变前后的具体物 | ce30 |
| 11 | **复刻有没有漏掉原片的爆点/速度差/母题** | 只抄镜头顺序和时长，把"墨滴炸开"写成"缓缓晕开"、丢掉原片母题 → 形似而神不似 | 拆解时记下爆点/速度曲线/母题三现位置，复刻时一起写进张力表；结构锁死≠节奏锁死 | ce30 |
| 12 | **有没有问用户"有没有后期环节"就把转场移交后期** | 规格表写"后期叠墨晕遮罩"→ 用户直接拿生成片发布，看到全是硬切 | 交付前问清：无后期 → 把遮罩**合成进成品 MP4 交付**；有后期 → 规格表 + 明写"需手动叠"；或改用支持首尾帧续写的工具 | ce31 |
| 13 | **转场切点是设计秒数还是实测秒数** | 按设计 2.9/6.6/14.7s 叠遮罩 → 实测切点 4.0/5.75/14.5s 全错位，叠了也白叠 | `fps=4` 抽帧拼图肉眼定真实切点再放遮罩；合成后验峰值帧全盖、无黑场、无白亮斑、无残影 | ce32 |
| 14 | **有没有先拆原片转场手法就默认套墨晕遮罩** | 原片 7 处无一处用通用墨色遮盖，丝滑靠形变衔接（鸟飞远→山、纹→绸带、球→墨花）；套遮罩＝用原片没有的手法模拟，越调越不像、用户仍觉不丝滑 | 拿到参考片先 `fps=8` 逐帧拆每处转场形态，写"**A 的形态延展成 B**"的形变句进同一单元；墨晕遮罩仅作无后期时的兜底 | ce33 |
