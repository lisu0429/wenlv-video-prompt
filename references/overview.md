## 1. 结构 (Structural)

### 类型

实操方法论 + 模板库（逆向工程型）。不是"创意灵感集"，而是**从成片倒推出可复现的生成指令**的一套工程流程。

### 一句话主旨

把一条已发布的文旅短视频，拆成可量化的镜头语言与叙事结构，再转写成"占位符化、双版本、带负向约束与合规红线"的提示词模板，使任何人换掉人物/城市/场景就能复刻同类片子。

### 骨架（主要论点及其关系）

1. **先拆解、后创作**：一切提示词都必须建立在客观拆解数据上（分镜表、景别/机位/打光/调色/剪辑量化、包装层计数、声音参数），不靠观感形容。
2. **结构决定镜头**：先判定叙事结构（一句话 + 分段），再按段落分配镜头与节奏；结构可替换，镜头跟着结构走。
3. **提示词四件套**：全局风格前缀 + 分镜提示词 + 负向约束 + 声音写法；每条提示词都以"客观可验证"收尾。
4. **双版本交付**：同一段提示词给"模板版（带 `{{占位符}}`）"与"本片示例版（原值可直复刻）"两栏。
5. **变量化是复用关键**：把人物、城市、场景、文化元素、美食抽成槽位表；城市级内容用"五连槽"（赛事—生态—历史—文博—美食）一键换城。
6. **合规是硬约束**：禁用夸大/绝对化/排名/功效承诺词，用"客观化改写三步"把主观赞美换成画面可见事实。
7. **包装与声音是半条命**：字幕/花字/文字标注/贴纸/转场/片尾引导的规格与卡点，以及 BPM 分段、音效卡点、人声与纯 BGM 的选择，单独成层交付。
8. **交付闭环**：使用说明（替换规则）→ 拆解 → 模板 → 包装 → 声音 → 复刻清单 → 待确认项。

**论点之间的关系**: 递进 + 依赖。1 是地基，2 是设计，3–5 是转写与复用，6 是约束条件，7 是完成度，8 是交付形态。

### 作者要解决的核心问题

"看到一条效果不错的文旅片，如何不复刻原片内容、只复刻它的方法，快速产出同类型但属于自己城市/人物的片子？"——即**把爆款从"作品"变成"可执行的生产说明书"**。

## 2. 解释 (Interpretive)

### 关键术语（作者本人的用法）

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 拆解报告 | 对成片做的结构化客观记录：结论、角色场景、叙事结构、分镜表、剪辑包装、声音、画面测量、复刻要点、不确定点 | 不是影评，不含好坏评价，只记录"是什么、怎么做的" |
| 分镜表 | 逐镜的 #／时间／时长／判断（AI/实拍/模板）／置信度／叠加层／转场 | 不是分镜脚本（没有画面描述），是"已发生事实"的测量表 |
| 画面基准 | 景别比例、机位比例、运镜、主光方位、光比、色温、调色倾向、每分钟刀数、平均镜头时长 | 不是拍摄方案；作者明确说"这是画面里的光影，用于写生成提示词" |
| 制作方式 | AI 生成视频／实拍／代码模板渲染，附置信度与 ⚠ 待复核标记 | 不是二选一的标签，允许"混合制作"并记录证据不足 |
| 包装层 | 字幕、花字、文字标注、贴纸/动图、转场、常驻图层、片尾引导卡 | 不是"后期"，是与画面同级的独立交付层，有计数与卡点 |
| 花字 | 字号大、多色/渐变、倾斜的强调字（如"真""看"） | 区别于普通字幕：有情绪与强调功能 |
| 文字标注 | 跟随物体或地点的说明性文字（地名、账号、技术名词） | 常被误当字幕；作者单列并统计"跟随移动"数量 |
| 变量槽位 | 提示词中的 `{{placeholder}}` 与默认值映射表 | 不是程序变量，是"换城市时改哪里"的清单 |
| 模板版 / 示例版 | 模板版带占位符用于定制；示例版填原值用于复刻原片 | 双版本并存，避免"改完就丢失原片参照" |
| 五连槽 | 赛事/活力—生态/标志物—历史/古道—文博/科技—美食/烟火 | 专用于"一城物产清单"型结构，换城时逐槽替换 |
| 客观化改写 | 主观评价→可验证事实；程度副词→画面元素；排名/极值/承诺→删除或中性化 | 不是"润色"，是有明确禁用词清单的合规改写 |
| 生成单元 | 把连续若干镜头打包成一次生成任务（如 G1=镜头1） | 不等于单镜头：受模型单次时长限制，按叙事段落合并 |

### 核心命题（用自己的话）

1. 提示词的质量上限由拆解的颗粒度决定；没有分镜级测量的"感觉描述"无法稳定复现。
2. 爆款的复用单位不是"创意"，而是"结构 + 节奏 + 画面基准"三件套。
3. 一条片子只保留一个可变主角 + 若干地标镜头，是最省成本又最具延展性的结构。
4. 每 3–8 秒必须换一次视觉证据（新场景/新景别/新包装），否则竖屏完播率会掉。
5. 开场 3 秒用"反差"（古人拿手机、不露脸悬念、反常画面）比用风景空镜更有效。
6. 结尾必须有转化位（账号引导/搜索卡），否则片子只是"好看"，不产生行动。
7. 生成提示词必须写"可被相机验证"的内容（颜色、材质、光位、动作），写形容词会让模型自由发挥。
8. 负向约束与正向描述同等重要：不生成字幕/水印/换脸/变形，否则后期返工成本高于生成成本。
9. 合规不是附加项：官方号语境下，一个"最"字就可能让整条片子不可发布，因此合规要写进提示词本身。
10. 模板的价值在于"边界清晰"：说清哪些能换、哪些必须保留（结构、节奏、合规），才不会改成四不像。
11. 拆解结论要标注置信度与不确定点；把"判不准"如实写出，比强行给结论更可复现。

### 论证链

作者用 27 条真实成片做样本：每条先由工具产出 `breakdown.json` / `report.md`（镜头切分、画面统计、声音分析），再由人写成 `拆解报告.md`（结论 + 结构 + 分镜 + 包装 + 测量 + 复刻要点），最后转写成 `拆解视频的提示词.md`（使用说明 + 全局 + 分镜 + 包装 + 声音 + 清单）。27 条覆盖穿越串场、探店、超现实微缩、文物复活、视觉诗、快剪、爽文短剧、CG、仙侠、方言梗、情感叙事、AIGC 长片等类型，证明"拆解→模板"流程可跨类型复用。

## 3. 批判 (Critical) ★

### 作者的时代局限

- 全部样本是 2026 年竖屏短视频生态（抖音为主），默认"前 3 秒钩子 + 高频切换 + 大字包装"是唯一解；这套假设在横屏中长视频、视频号/小红书图文、海外平台未必成立。
- 提示词写法受当前生成模型能力约束（单次 5–10 秒、文字易乱码、人脸一致性差），模型升级后"按镜头拆分"的必要性会下降。
- 27 条中多条标注"待确认"（实拍/AI 判定、BPM、配乐来源），说明拆解工具本身仍在早期，数据并非全部可信。

### 作者的立场盲点

- 站在**官方文旅号**视角：重宣传、重地标覆盖、重账号引导；缺少个人创作者关心的"低成本单兵拍摄""带货转化""系列化更新"路径。
- 样本以"视觉奇观"为主，缺少"人味"（真实游客、素人反应、口播知识密度）的对照样本，容易高估特效与包装的权重。
- 未讨论投放与数据反馈：拆解到"发布"为止，没有"发布后如何按完播率/互动率迭代"的环节。

### 未被证明的假设

- 假设"量化指标（景别占比、刀/分钟、光比）达标 = 片子有效"，但这些指标与完播率/转化的因果关系未给出证据。
- 假设"换城市只换槽位"就能成立，但不同城市的资源禀赋差异很大（有的城市没有赛事、没有熊猫级 IP），五连槽可能硬凑。
- 假设"客观化描述"不会损害传播力，但短视频的情绪钩子往往正来自主观感叹；合规与感染力之间的平衡未论证。

### 最强反对意见

这套模板会生产出**高度同质化**的内容：所有城市都变成"一个人 + 五段物产清单"，观众看三条就会疲劳；平台算法也会因"结构雷同"降低推荐。真正的爆款来自不可复制的具体性（一个真实的人、一个意外的瞬间），而模板恰恰把具体性抽象掉了。

> **以上批判会直接成为下游 skill 的 Boundary (B) 字段来源**
